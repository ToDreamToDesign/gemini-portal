網頁版

DREAM LED 電視牆

輸入屏幕寬高，算出片數、箱數、杯架，並規劃主訊、備訊、電源三張配線圖與線材備料清單。可匯出 PNG。

Windows 桌面版

一鍵去背組

去背工具組，本機運算，檔案不會上傳。第一次用某模型會自動下載模型檔，需連網。

圖片去背，可輸出透明 PNG、綠背、白底、黑底或自選色。

圖像去背工具 約 136 MB，解壓縮後執行「一鍵去背.exe」 說明與原始碼

影片去背，可輸出綠背、透明或換底色，保留聲音。

影像去背工具 準備中，尚未發佈
Windows 桌面版

音樂下載器

YouTube 轉 MP3，支援批次清單與整批音量校正。啟動時自動檢查更新。請只下載你擁有版權或已獲授權的內容。

下載 exe 約 196 MB，單檔免安裝 說明與原始碼
Windows 的安全提示 兩個桌面程式沒有數位簽章，第一次執行時 Windows SmartScreen 可能跳出警告。選「其他資訊」→「仍要執行」即可。
